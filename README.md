# 🔍 链式提示智能问答系统

一个基于链式提示（Chain-of-Thought Prompting）的智能问答系统，通过"信息提取→精准回答"两阶段流程，降低大模型在长文档问答中的幻觉风险。

## 📌 项目背景

用大模型阅读长文档（网页、PDF）并回答问题时，经常遇到两个问题：
- **幻觉**：模型回答了文档中不存在的内容
- **不可追溯**：不知道模型的回答依据是什么

本项目通过**链式提示**设计，让模型的推理过程可观察、可验证。

## 🎯 核心设计
这个项目的核心设计是将传统的一步式文档问答拆解为"信息提取→精准回答"两阶段链式提示流程：第一步让模型作为"信息提取器"从
  长文档中精准抽取与问题相关的事实和数据，第二步再让模型作为"问答助手"严格基于提取出的关键信息生成回答，从而将模型的推理
  过程外显化——用户不仅能看到最终答案，还能看到答案的依据（中间提取信息），以此降低大模型在长文档问答中的幻觉风险，并使回
  答变得可追溯、可验证。
